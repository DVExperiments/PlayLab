How it works

  1. Describe a project, idea or plan you’re working on.
  2. List what you’re assuming is true. Use the four types to find assumptions you might not have noticed.
  3. Rate each one: how much would it matter if you were wrong, and how much evidence do you have?
  4. Plan quick tests for the assumptions that land in the top-left corner, then reflect.
